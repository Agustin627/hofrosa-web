Precios de la carta

Entrar con su token de GitHub

Solo puede cambiar precios quien tenga un token de GitHub con permiso sobre la web. El token es una llave larga que empieza con github_pat_. No se envía a ningún otro lugar: esta página habla solo con GitHub.

¿No tiene token? Créelo en 2 minutos
  1. Abra Crear token en GitHub e inicie sesión si se lo pide.
  2. En Repository access elija Only select repositories y marque solo hofrosa-web.
  3. En Permissions revise que Contents diga Read and write (ya viene marcado). No agregue otros permisos.
  4. Deje la fecha de vencimiento (90 días) y pulse Generate token.
  5. Copie el token y péguelo abajo. GitHub lo muestra una sola vez: guárdelo en su gestor de contraseñas, nunca en un archivo de la web.

Si el token se pierde o alguien más lo ve, bórrelo en GitHub (Settings → Developer settings → Personal access tokens) y cree otro.

El token se guarda cifrado (AES-256) en este navegador. Para usarlo hay que escribir la frase. Use al menos 12 caracteres; lo más seguro es una frase de cuatro palabras que no sea una cita conocida.

Desbloquear

Este dispositivo tiene un token guardado y cifrado. Escriba su frase para usarlo.
